2. Bereitstellung und Hosting der Website

Diese Website wird als statische Website über GitHub Pages bereitgestellt, einen Dienst von GitHub. Beim Aufruf der Website werden technisch erforderliche Verbindungs- und Nutzungsdaten verarbeitet. Dazu gehören insbesondere die IP-Adresse, Datum und Uhrzeit des Zugriffs, die aufgerufene Seite beziehungsweise Datei sowie technische Angaben zum verwendeten Browser und Gerät. GitHub dokumentiert, dass beim Besuch einer GitHub-Pages-Website die IP-Adresse des Besuchers unabhängig von einer Anmeldung zu Sicherheitszwecken protokolliert und gespeichert wird.

Die Verarbeitung erfolgt, soweit sie in unserer Verantwortung liegt, auf Grundlage von Art. 6 Abs. 1 Buchst. f DSGVO. Unser berechtigtes Interesse besteht in der sicheren, stabilen und technisch zuverlässigen Bereitstellung der Website sowie in der Abwehr von Missbrauch und Angriffen.

Bei der Bereitstellung können GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA, und GitHub B.V., Prins Bernhardplein 200, 1097 JB Amsterdam, Niederlande, Daten verarbeiten. GitHub beschreibt die Verarbeitung in seiner Datenschutzerklärung und weist darauf hin, dass Daten auch in den USA und anderen Staaten verarbeitet werden können. Für Übermittlungen aus der Europäischen Union nennt GitHub insbesondere das EU-US Data Privacy Framework und die Standardvertragsklauseln der Europäischen Kommission als Übermittlungsmechanismen.
